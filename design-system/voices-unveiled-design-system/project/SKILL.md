Read the `readme.md` file within this skill, and explore the other available files.

If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy
assets out and create static HTML files for the user to view. If working on
production code, you can copy assets and read the rules here to become an expert in
designing with this brand.

If the user invokes this skill without any other guidance, ask them what they want
to build or design, ask some questions, and act as an expert designer who outputs
HTML artifacts _or_ production code, depending on the need.

## Quick reference

- **Foundations:** `styles.css` (links every token) + `tokens/` (colors, type,
  spacing, effects, fonts). Plum `#4B2142` primary on Soft Ivory `#FAF6EF`;
  Libre Baskerville (serif headlines/quotes) + Inter (UI).
- **Components:** `components/` — Button, Tag, Badge, SafetyNote, ImpactCard,
  StoryCard, Testimonial, DonationSelector, CampaignBanner, Field, Input. Each
  has a `.prompt.md` with usage. Consumed via the compiled `_ds_bundle.js`.
- **Guidelines cards:** `guidelines/` — visual specimens for colors, type, spacing,
  brand.
- **UI kit:** `ui_kits/website/` — interactive marketing-site recreation.

## Brand non-negotiables

- Speak with **dignity, not pity**; emphasize agency over victimhood.
- Always include the **safety note** wherever student stories/images appear.
- **No emoji** in product UI. Warm, calm, hopeful — never alarmist or "crisis NGO".
- Represent students with abstract brand art or approved/consented photography —
  never voyeuristic or trauma-spectacle imagery.
- Use real 2024 impact figures (115 scholarships, 50 internet, 20 intern grads,
  8 volunteers/mentorships).
