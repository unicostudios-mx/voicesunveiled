One-line: A small pill label for program categories, story topics, and filters, available in the brand's tonal palette.

```jsx
<Tag tone="sage">Mental health</Tag>
<Tag tone="terracotta">Leadership</Tag>
```

Tones map to the palette: `plum` (default) · `terracotta` · `gold` · `sage`
(care/wellbeing) · `midnight` (institutional) · `neutral`. Tints are soft washes
with a readable same-hue text color.
