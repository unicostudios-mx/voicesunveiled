One-line: A solid, uppercase status or count badge for stronger emphasis than a Tag (e.g. "Urgent", "New").

```jsx
<Badge tone="gold">Urgent</Badge>
<Badge tone="success">Funded</Badge>
```

Tones: `plum` (default) · `gold` · `terracotta` · `success` · `danger`. Use
sparingly — solid fills draw the eye.
